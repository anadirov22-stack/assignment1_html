About the Project

This project is about Doner na Abaya, a fast-food restaurant in Astana. I chose this restaurant because it is a real place that I could visit. During my visit, I collected information about its services, working hours and location, and took several photos for the website.

The website was created as part of an HTML project. While making the pages, I used different HTML elements that we learned in class.

This Colophon page shows some of the HTML elements used in the project. The code element displays a short piece of HTML code, the pre element keeps the original formatting of text, the kbd element is used for keyboard shortcuts, and the samp element shows computer output.

While working on this project, I got more practice with HTML and learned how different elements can be used on a real website. I also learned how to organize information so that it is easier to read and navigate.
